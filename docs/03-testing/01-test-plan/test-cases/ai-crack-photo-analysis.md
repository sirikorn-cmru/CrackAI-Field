# Test Case: ถ่ายภาพและประเมินรอยร้าวด้วย AI พร้อมทางเลือกกรอกเอง (Human-in-the-loop)

อ้างอิง: [[feature-list#4. ถ่ายภาพและประเมินรอยร้าวด้วย AI พร้อมทางเลือกกรอกเอง (Human-in-the-loop)|ฟีเจอร์ 4]] · [[user-journey#Journey: ผู้สำรวจภาคสนามลงพื้นที่สำรวจอาคาร|journey ผู้สำรวจภาคสนาม]] ขั้นตอน 9-17 · [[acceptance-criteria#4. ถ่ายภาพและประเมินรอยร้าวด้วย AI พร้อมทางเลือกกรอกเอง (Human-in-the-loop)|acceptance-criteria]]

ฟีเจอร์นี้เป็นความเสี่ยงเฉพาะของระบบ (human-in-the-loop) — ทุก test case ต้องยืนยันว่า AI ไม่เคยบันทึกผลสรุปสุดท้ายเองโดยอัตโนมัติ และเส้นทางกรอกเอง (FR-29) ต้องใช้งานได้เสมอในฐานะเส้นทางปกติ ไม่ใช่ทางออกฉุกเฉินที่เปิดให้เฉพาะตอน AI ล้มเหลว

หมายเหตุ: TC-04-08 ถึง TC-04-10 ทดสอบพฤติกรรมที่สังเกตได้ของกรณี "AI วิเคราะห์ไม่สำเร็จ" เท่านั้น ไม่อ้างอิงเกณฑ์ตัวเลข/threshold ใดๆ เนื่องจากยังไม่มีการกำหนดในขั้นตอนออกแบบเชิงเทคนิค
