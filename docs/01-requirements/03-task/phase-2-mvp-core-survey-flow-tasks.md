# Phase 2 — งานย่อย: MVP Core สำรวจและประเมินความเสียหายอาคารแบบออฟไลน์ครบวงจร พร้อมรับรองผลและภาพรวม

อ้างอิงแผนหลัก: [[release-plan]] · แหล่งความต้องการ: [[backlog]], [[feature-list]]

งานย่อยด้านล่างเขียนในระดับความสามารถเชิงตรรกะ/ผลลัพธ์ที่ผู้ใช้สังเกตได้เท่านั้น เพราะเอกสารชั้นนี้เป็นชั้นแผนงานระดับความสามารถ ไม่ใช่ชั้นออกแบบเชิงเทคนิค — รายละเอียด stack ที่ตัดสินใจแล้วดูได้ที่ `docs/02-design/02-technical/technology-stack.md` และการออกแบบระดับ component ที่ผูกกับ stack นั้นดูได้ที่ `docs/02-design/02-technical/detailed-design/` ทุก task ในเฟสนี้พึ่งพารากฐานจาก Phase 1 (การเข้าสู่ระบบและการบันทึก/ซิงค์ข้อมูลออฟไลน์) โดยปริยาย จึงไม่ระบุ dependency ข้าม phase ซ้ำในตาราง

| รหัส Task | ชื่องาน | รหัส FR/NFR | หมายเหตุ dependency ภายใน phase |
|---|---|---|---|
| T-2-01 | บันทึกข้อมูลทั่วไปของอาคาร (ชื่อ เจ้าของ ที่ตั้ง การใช้สอย กรรมสิทธิ์) | FR-01 | ไม่มี — เป็นจุดเริ่มต้นของการสำรวจแต่ละอาคาร |
| T-2-02 | บันทึกพิกัด GPS ของอาคาร ตามเกณฑ์ความแม่นยำที่กำหนด | FR-02, NFR-06 | dep: T-2-01 |
| T-2-03 | บันทึกข้อมูลทางกายภาพของอาคาร (จำนวนชั้น พื้นที่ ชนิดโครงสร้าง วัสดุ) | FR-03 | dep: T-2-01 |
| T-2-04 | บันทึกอันตรายของสภาพแวดล้อมโดยรอบอาคารที่ส่งผลกระทบ (อาคารข้างเคียง ลาดเชิงเขา ดินทรุดตัว) | FR-04 | dep: T-2-01 |
| T-2-05 | บันทึกความเสียหายที่สังเกตจากภายนอกอาคาร | FR-05 | dep: T-2-01..04 |
| T-2-06 | บันทึกความเสียหายของโครงสร้างอาคารแยกตามชนิดวัสดุและตำแหน่ง | FR-06 | dep: T-2-01..04 |
| T-2-07 | บันทึกความเสียหายของโครงสร้างอื่นๆ (โครงหลังคา) | FR-07 | dep: T-2-06 — ใช้ผลลัพธ์ร่วมกับ T-2-06 ในการคำนวณสรุปผล T-2-10 |
| T-2-08 | บันทึกความเสียหายของส่วนประกอบอาคาร (ผนัง ฝ้าเพดาน วัสดุมุงหลังคา) | FR-08 | dep: T-2-01..04 |
| T-2-09 | บันทึกความเสียหายของระบบไฟฟ้าและระบบอื่นๆ | FR-09 | dep: T-2-01..04 — ผลลัพธ์ใช้ร่วมกับสรุปผล T-2-10 |
| T-2-10 | สรุปผลการประเมินความเสียหายเป็น 3 ระดับสี (เขียว/เหลือง/แดง) จากทุกหมวดที่กรอกไว้ | FR-10 | dep: T-2-05, T-2-06, T-2-07, T-2-08, T-2-09 |
| T-2-11 | แสดงเกณฑ์อ้างอิงจากคู่มือประกอบแต่ละหมวดการประเมินขณะกรอกข้อมูลในแอป | FR-11 | dep: T-2-05..09 (ใช้งานคู่กับแต่ละหมวด) |
| T-2-12 | ถ่ายภาพประกอบความเสียหายผูกกับตำแหน่ง/บริเวณที่ระบุไว้ | FR-12 | dep: T-2-05..09 (ต้องมีบริเวณ/หมวดความเสียหายให้ผูกภาพ) |
| T-2-13 | กรอกระดับความเสียหายของรอยร้าวด้วยตนเองโดยไม่ต้องพึ่ง AI (เส้นทางปกติของการประเมินรอยร้าว) | FR-29 | dep: T-2-12 |
| T-2-14 | บันทึกข้อมูลผู้สำรวจ (สูงสุด 3 คน) และหัวหน้าผู้สำรวจพร้อมหน่วยงาน/โทรศัพท์/ตำแหน่ง | FR-16 | ไม่มี |
| T-2-15 | บันทึกวันที่และเวลาเริ่ม/เวลาแล้วเสร็จของการสำรวจแต่ละอาคาร | FR-17 | dep: T-2-14 |
| T-2-16 | หัวหน้าผู้สำรวจตรวจทานผลการสำรวจของทีมทั้งหมด และส่งกลับให้แก้ไขได้ก่อนรับรอง | FR-19 | dep: T-2-01..15 (ต้องมีผลสำรวจครบก่อนตรวจทาน) |
| T-2-17 | ลงลายมือชื่อดิจิทัลของหัวหน้าผู้สำรวจเพื่อรับรองผลสรุปอย่างเป็นทางการ | FR-18 | dep: T-2-16 |
| T-2-18 | เก็บประวัติการแก้ไขข้อมูลผลประเมินไว้ตรวจสอบย้อนหลัง | NFR-05 | dep: ทำงานคู่กับทุก task ที่มีการบันทึก/แก้ไขข้อมูลในเฟสนี้ (โดยเฉพาะ T-2-05..09, T-2-13, T-2-16, T-2-17) |
| T-2-19 | แสดง dashboard ภาพรวมจำนวนอาคารที่สำรวจแล้วและสัดส่วนตามระดับสี แยกตามพื้นที่/จังหวัด | FR-22 | dep: T-2-10, T-2-17 (นับเฉพาะผลที่รับรองแล้ว) |
