# Phase 3 — งานย่อย: เสริมการวิเคราะห์รอยร้าวด้วย AI และภาพประกอบเพิ่มเติม

อ้างอิงแผนหลัก: [[release-plan]] · แหล่งความต้องการ: [[backlog]], [[feature-list]]

งานย่อยด้านล่างเขียนในระดับความสามารถเชิงตรรกะ/ผลลัพธ์ที่ผู้ใช้สังเกตได้เท่านั้น ไม่ผูกกับ tech stack ใดๆ เนื่องจาก `technology-stack.md` ยังไม่มีการตัดสินใจ ทุก task ในเฟสนี้ต่อยอดจากความสามารถถ่ายภาพและกรอกระดับความเสียหายด้วยตนเองที่ส่งมอบไว้แล้วใน Phase 2 (T-2-12, T-2-13)

| รหัส Task | ชื่องาน | รหัส FR/NFR | หมายเหตุ dependency ภายใน phase |
|---|---|---|---|
| T-3-01 | วิเคราะห์ภาพถ่ายรอยร้าวโดยอัตโนมัติเพื่อประมาณความกว้างของรอยแตกร้าวและเสนอระดับความเสียหายเป็นค่าตั้งต้น | FR-13 | ไม่มีภายในเฟสนี้ (พึ่ง T-2-12 ของ Phase 2 ในการมีภาพถ่ายให้วิเคราะห์) |
| T-3-02 | ให้ผู้สำรวจยืนยันหรือแก้ไขผลวิเคราะห์อัตโนมัติก่อนบันทึกเป็นผลจริงเสมอ (human-in-the-loop ห้ามบันทึกอัตโนมัติโดยไม่มีผู้ตรวจสอบ) | FR-14 | dep: T-3-01 |
| T-3-03 | ตรวจจับและแจ้งกรณีวิเคราะห์ภาพไม่สำเร็จ (เช่น ภาพเบลอ แสงไม่พอ ไม่พบรอยร้าวในภาพ) พร้อมแจ้งสาเหตุและเสนอทางเลือกถ่ายภาพใหม่ทันทีในหน้างานเดียวกัน | FR-28 | dep: T-3-01 |
| T-3-04 | วาด/เขียนภาพประกอบเพิ่มเติมนอกเหนือจากภาพถ่าย ตามหมวด "พื้นที่สำหรับวาดภาพประกอบที่จำเป็น" ของแบบฟอร์มต้นฉบับ | FR-15 | ไม่มี — เป็นความสามารถเสริมอิสระจาก T-3-01..03 |

## สรุป

จำนวนงานย่อยทั้งหมดใน Phase นี้: **4 tasks** ครอบคลุม FR-13, FR-14, FR-15, FR-28 ครบทุกรหัสที่กำหนดไว้ใน [[release-plan#Phase 3 — เสริมการวิเคราะห์รอยร้าวด้วย AI และภาพประกอบเพิ่มเติม|release-plan (Phase 3)]]
