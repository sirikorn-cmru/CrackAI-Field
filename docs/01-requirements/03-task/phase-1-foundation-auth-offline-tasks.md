# Phase 1 — งานย่อย: รากฐานระบบ (ยืนยันตัวตน สิทธิ์ตามบทบาท และสถาปัตยกรรมออฟไลน์-ซิงค์)

อ้างอิงแผนหลัก: [[release-plan]] · แหล่งความต้องการ: [[backlog]], [[feature-list]]

งานย่อยด้านล่างเขียนในระดับความสามารถเชิงตรรกะ/ผลลัพธ์ที่ผู้ใช้สังเกตได้เท่านั้น ไม่ผูกกับ tech stack ใดๆ เนื่องจาก `technology-stack.md` ยังไม่มีการตัดสินใจ

| รหัส Task | ชื่องาน | รหัส FR/NFR | หมายเหตุ dependency ภายใน phase |
|---|---|---|---|
| T-1-01 | สร้าง/แก้ไข/ปิดการใช้งานบัญชีผู้ใช้ และกำหนดบทบาทให้แต่ละบัญชี | FR-21 | ไม่มี — ต้องเสร็จก่อน T-1-02, T-1-04, T-1-10 เพราะต้องมีบัญชี/บทบาทให้ตรวจสอบสิทธิ์ |
| T-1-02 | ยืนยันตัวตนผู้ใช้ด้วยบัญชี (เข้าสู่ระบบ/ออกจากระบบ) ขณะมีสัญญาณอินเทอร์เน็ต | FR-25 | dep: T-1-01 |
| T-1-03 | บังคับแสดง/อนุญาตเฉพาะฟังก์ชันและหน้าจอที่ตรงกับบทบาทของผู้ใช้หลังเข้าสู่ระบบสำเร็จ | FR-26 | dep: T-1-01, T-1-02 |
| T-1-04 | เข้าสู่ระบบและใช้งานแอปได้ขณะไม่มีการเชื่อมต่ออินเทอร์เน็ต ด้วย credential/session ที่แคชไว้จากการเชื่อมต่อสำเร็จครั้งล่าสุด | FR-27 | dep: T-1-02 |
| T-1-05 | กำหนดอายุการใช้งานของ credential/session ที่แคชไว้ขณะออฟไลน์ และบังคับยืนยันตัวตนใหม่กับระบบเมื่อครบกำหนดหรือเมื่อกลับมามีสัญญาณ | NFR-09 | dep: T-1-04 |
| T-1-06 | บันทึกข้อมูลทุกหมวดของการสำรวจลงที่เก็บข้อมูลบนอุปกรณ์ได้อย่างสมบูรณ์ขณะไม่มีสัญญาณอินเทอร์เน็ต | NFR-01 | ไม่มี — เป็นรากฐานของ T-1-07, T-1-08, T-1-09 |
| T-1-07 | รับประกันความเร็วและความเสถียรของการบันทึกข้อมูลบนอุปกรณ์และการซิงค์ขึ้นระบบกลางตามเป้าหมายที่กำหนด | NFR-02 | dep: T-1-06 |
| T-1-08 | ตรวจจับและรวม (merge) ข้อมูลที่ถูกแก้ไขจากหลายอุปกรณ์เข้าด้วยกันโดยอัตโนมัติเมื่อไม่ขัดแย้งกัน และตั้งสถานะรอแก้ไขด้วยมือเมื่อ merge อัตโนมัติไม่ได้ | NFR-03 | dep: T-1-06, T-1-07 |
| T-1-09 | ให้แอปใช้งานได้ดีบนอุปกรณ์พกพาหลากหลายรุ่นและสภาพแวดล้อมกลางแจ้งที่ผู้สำรวจภาคสนามใช้งานจริง | NFR-04 | dep: T-1-06 |
| T-1-10 | รองรับหลายทีม/อุปกรณ์จำนวนมากซิงค์ข้อมูลพร้อมกันหลังเกิดเหตุ โดยไม่ลดทอนความเร็ว/ความเสถียรของระบบ | NFR-07 | dep: T-1-06, T-1-07, T-1-08 |
| T-1-11 | จำกัดการเข้าถึงข้อมูลเฉพาะผู้ใช้ที่มีสิทธิ์ตามบทบาทที่ได้รับ ทั้งขณะเรียกดูและแก้ไขข้อมูล | NFR-08 | dep: T-1-01, T-1-03 |
