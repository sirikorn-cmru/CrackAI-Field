# Phase 4 — งานย่อย: เครื่องมือบริหารจัดการส่วนกลาง (มอบหมายงาน ค้นหา/ส่งออกรายงาน แก้ไขข้อมูลขัดแย้ง และตรวจสอบย้อนหลัง)

อ้างอิงแผนหลัก: [[release-plan]] · แหล่งความต้องการ: [[backlog]], [[feature-list]]

งานย่อยด้านล่างเขียนในระดับความสามารถเชิงตรรกะ/ผลลัพธ์ที่ผู้ใช้สังเกตได้เท่านั้น ไม่ผูกกับ tech stack ใดๆ เนื่องจาก `technology-stack.md` ยังไม่มีการตัดสินใจ ทุก task ในเฟสนี้ต่อยอดจาก dashboard และข้อมูลสำรวจที่รับรองแล้วใน Phase 2 (T-2-19) และกลไกตรวจจับความขัดแย้งอัตโนมัติใน Phase 1 (T-1-08) — T-4-07/T-4-08 (เพิ่ม 2026-09-03) อ้างอิงเหตุการณ์ที่เกิดขึ้นจริงข้าม phase เพิ่มเติม ได้แก่ การบันทึกประวัติจากกลไก audit trail และการรับรอง/ส่งกลับแก้ไขใน Phase 2 (T-2-16, T-2-17, T-2-18), ข้อมูลอาคาร/พื้นที่ใน Phase 2 (T-2-01) และการแก้ไขผลวิเคราะห์ AI ใน Phase 3 (T-3-02) — หมายเหตุ: หากทำ Phase 4 ก่อน Phase 3 เสร็จ หน้าประวัติของ T-4-07 จะยังไม่มีเหตุการณ์แก้ไขผล AI ให้แสดงจนกว่า Phase 3 จะเสร็จ (ดูรายละเอียดใน [[release-plan#ตารางสรุป Phase ↔ FR/NFR ↔ เหตุผล|release-plan]])

| รหัส Task | ชื่องาน | รหัส FR/NFR | หมายเหตุ dependency ภายใน phase |
|---|---|---|---|
| T-4-01 | สร้างและมอบหมายรายการอาคาร/พื้นที่ที่ต้องสำรวจให้สมาชิกทีม | FR-20 | ไม่มี |
| T-4-02 | ค้นหา/กรองรายการอาคารที่สำรวจแล้วตามพื้นที่ ระดับสีผลสรุป ช่วงวันที่สำรวจ หรือผู้สำรวจ/หัวหน้าผู้สำรวจ | FR-24 | ไม่มี |
| T-4-03 | แสดงรายการระเบียนที่มีความขัดแย้งของข้อมูลรอการแก้ไขด้วยมือ ให้เฉพาะหัวหน้าผู้สำรวจหรือผู้ดูแลระบบเห็น | FR-30 | ไม่มีภายในเฟสนี้ (พึ่ง T-1-08 ของ Phase 1 ในการตั้งสถานะรอแก้ไข) |
| T-4-04 | เปรียบเทียบข้อมูลทุกเวอร์ชันที่ขัดแย้งกันแบบเคียงข้างกัน (ค่าเดิม/ค่าใหม่ อุปกรณ์ที่บันทึก ผู้แก้ไข เวลาที่บันทึก) และเลือกเก็บค่าจากเวอร์ชันใดเวอร์ชันหนึ่งทั้งหมดหรือรวมค่าเป็นรายฟิลด์ ก่อนบันทึกผลลัพธ์เป็นข้อมูลจริงชุดเดียวและปลดสถานะขัดแย้ง | FR-31 | dep: T-4-03 |
| T-4-05 | กันระเบียนที่ยังค้างสถานะขัดแย้งไม่ให้ถูกนับรวมใน dashboard หรือรายงานที่ส่งออก จนกว่าจะแก้ไขเสร็จและปลดสถานะแล้ว | NFR-10 | dep: T-4-03, T-4-04 (และอ้างอิง dashboard จาก T-2-19 ของ Phase 2) |
| T-4-06 | ส่งออกผลการสำรวจรายอาคารหรือสรุปภาพรวมเป็นไฟล์เพื่อใช้งานต่อนอกระบบ | FR-23 | dep: T-4-05 (ต้องกันระเบียนที่ยังขัดแย้งออกจากรายงานก่อนส่งออก) |
| T-4-07 | แสดงประวัติการแก้ไขผลประเมินรายอาคารเรียงตามลำดับเวลา ครอบคลุมเหตุการณ์แก้ไขผลวิเคราะห์ AI รับรอง/ส่งกลับแก้ไขผล แก้ไขความขัดแย้งด้วยมือ และเหตุการณ์ซิงค์สำเร็จ/ตรวจพบความขัดแย้งที่ระบบบันทึกเอง ให้เฉพาะหัวหน้าผู้สำรวจ (เห็นเฉพาะทีม/อาคารของตน) ผู้ดูแลระบบ และหน่วยงานส่วนกลางเข้าถึงได้ | FR-32 | dep: T-4-04 (ต้องมีผลแก้ไขความขัดแย้งเป็นหนึ่งในเหตุการณ์ที่แสดง) — และอ้างอิงข้อมูลจาก T-1-08 (Phase 1), T-2-16/T-2-17/T-2-18 (Phase 2), T-3-02 (Phase 3) นอกเฟสนี้ |
| T-4-08 | ค้นหา/กรองประวัติการแก้ไขทั่วทั้งระบบตามช่วงเวลา ผู้แก้ไข ประเภทการกระทำ และพื้นที่ ให้เฉพาะผู้ดูแลระบบและหน่วยงานส่วนกลางเข้าถึงได้ | FR-33 | dep: T-4-07 (ใช้ชุดข้อมูลประวัติเดียวกันแต่ขยายขอบเขตการค้นหาทั่วทั้งระบบแทนรายอาคาร) — และอ้างอิงข้อมูลพื้นที่/อาคารจาก T-2-01 (Phase 2) |
